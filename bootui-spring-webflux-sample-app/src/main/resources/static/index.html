Inspect a waiting worker

        

          Open Threads in another tab before starting.
          No Java agent needed.
        

        

          Virtual workers are not listed. On JDK 21+, restart this sample with
          --spring.threads.virtual.enabled=false for a visible worker.
        

        

          How to inspect the request
          

            Choose Live in Thread source, or use
            Capture snapshot → Contention while the request runs.
            Observe threads → Observe & compare shows the sampled interval.
            Waiting alone is not evidence of contention or a deadlock.
            Explicit snapshots and observations also work with low-footprint mode on.
